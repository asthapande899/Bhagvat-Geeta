# Bhagavad Gita AI Counselor

A custom Flask web application that serves as a spiritual counselor. It answers your life's struggles using the eternal wisdom of the Bhagavad Gita, delivering compassionate, short, and highly empathetic responses in a warm Indian male voice, accompanied by soothing background meditation music.

## Key Features
*   **AI Lord Krishna Voice**: Realistic Indian male neural voice speaking at a calm, meditative pace.
*   **Soothing Music**: Instrumental ambient music ("Ethereal Relaxation" by Kevin MacLeod) looping in the background.
*   **Gita RAG Search**: Retrieves relevant Sanskrit verses and translations matching the context of your worries.
*   **Offline Fallback**: Gracefully falls back to beautiful pre-configured offline guidance if API keys run out.
